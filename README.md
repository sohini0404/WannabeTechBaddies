# FlowShield
### Flood Simulation & Early Warning Dashboard

FlowShield is a disaster management and flood monitoring platform designed to help citizens, authorities, and emergency responders prepare for and respond to flood situations.

The platform provides flood severity prediction, simulation-based risk analysis, emergency contact information, and disaster preparedness guidance through an intuitive dashboard.

---

## Problem Statement

Floods cause significant damage to lives, infrastructure, and resources every year. Citizens often lack access to timely information, flood risk analysis, and emergency response guidance.

FlowShield aims to bridge this gap by providing:

- Flood severity assessment
- Early warning insights
- Simulation-based flood analysis
- Emergency contact information
- Safety and preparedness guidance
- Connects to national, state and NGO relief funds to make donations

Clone the repository:

```bash

```

```bash
cd WannabeTechBaddies
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```
